# ibm-watsonx-data-integration-agent-skills
Data integration skills enable external AI agents to interact seamlessly with IBM watsonx.data integration using natural language.

You can download and add skills to an external AI agent, such as Claude Desktop and IBM Bob, for the following watsonx.data integration features:

**Agentic Data Integration**

Use Agentic Data Integration to create production-grade data flows without data engineering expertise. Instead of manually configuring each stage of a flow, you describe your   data requirements in natural language. Your AI agent converts those requirements into a data flow. After you review and approve the flow, the agent can run, monitor, and optionally schedule a job for the flow.

You configure an external AI agent to connect to the hosted remote Agentic Data Integration MCP server and then add the data integration skills to the agent.

Download the `ibm-agentic-data-integration-skills.zip` file and then follow the instructions in [Integrating data with the MCP server](https://www.ibm.com/docs/en/watsonx/wdi/saas?topic=integration-agentic-data) in the IBM watsonx.data integration documentation.
