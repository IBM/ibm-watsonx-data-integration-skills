# DataStage Address Verification Stage

## Purpose
Validate, standardize, and correct postal addresses using address verification services and reference data.

## When to Use
- Validating postal addresses, including coordinates, against reference databases
- Standardizing address formats
- Correcting and enriching address data

## When NOT to Use
- For general data standardization (use Standardize stage)
- When address validation is not required
- For non-address data cleansing

## Requirements
- **Link Cardinality**: exactly 1 primary input, 1 to 2 primary outputs
