# DataStage Match Frequency Stage

## Purpose
Analyze and report on the frequency of matches between records to assess data quality and matching effectiveness.

## When to Use
- Analyzing match frequency patterns in datasets
- Assessing data quality and matching effectiveness
- Generating match statistics and reports
- Understanding duplicate patterns and distributions

## When NOT to Use
- For actual record matching (use Match stages)
- For simple counting (use Aggregator stage)
- When frequency analysis is not needed

## Requirements
- **Link Cardinality**: exactly 1 primary input
