# DataStage Two Source Match Stage

## Purpose
Match records from two input sources based on matching criteria to identify corresponding records across datasets.

## When to Use
- Matching records between two different data sources
- Identifying corresponding records across systems
- Data reconciliation between two sources

## When NOT to Use
- When only one source needs matching (use One Source Match stage)
- For simple joins (use Join stage)
- For lookups (use Lookup stage)

## Requirements
- **Link Cardinality**: unknown
