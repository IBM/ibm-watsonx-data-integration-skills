# DataStage Investigate Stage

## Purpose
Analyze and investigate data quality issues, patterns, and anomalies within datasets for data profiling and quality assessment.

## When to Use
- Data profiling and quality assessment
- Investigating data patterns, anomalies, and outliers
- Understanding data characteristics before transformation and cleansing

## When NOT to Use
- For simple data viewing and debugging (use Peek stage)
- For data transformation (use Transformer stage)

## Requirements
- **Link Cardinality**: Option 1: exactly 1 primary input; Option 2: 1 to 2 primary outputs
