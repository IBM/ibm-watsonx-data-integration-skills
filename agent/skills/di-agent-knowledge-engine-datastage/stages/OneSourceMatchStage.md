# DataStage One Source Match Stage

## Purpose
Match records within a single data source to identify duplicates or related records based on matching criteria.

## When to Use
- Identifying duplicate records within a single dataset
- Finding related records in the same source
- Data deduplication and cleansing operations

## When NOT to Use
- When matching across two sources (use Two Source Match stage)
- For simple duplicate removal (use Remove Duplicates stage)
- For exact duplicate detection only

## Requirements
- **Link Cardinality**: unknown
