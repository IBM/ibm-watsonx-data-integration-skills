# DataStage Data Rules Stage

## Purpose
Apply business rules and data quality rules to validate, cleanse, and enforce data standards across datasets.

## When to Use
- Enforcing business rules and data quality standards
- Implementing data governance policies

## When NOT to Use
- For simple filtering (use Filter stage)
- For transformations without rules (use Transformer stage)

## Requirements
- **Link Cardinality**: any number of primary inputs
