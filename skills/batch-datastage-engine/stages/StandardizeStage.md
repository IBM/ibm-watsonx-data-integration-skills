# DataStage Standardize Stage

## Purpose
Standardize data values according to predefined rules and reference data to ensure consistency across datasets.

## When to Use
- Standardizing data formats and values
- Applying business rules for data consistency
- Converting data to standard representations
- Normalizing data values across sources

## When NOT to Use
- For address-specific standardization (use Address Verification stage)
- For simple transformations (use Transformer stage)
- When data is already in standard format

## Requirements
- **Link Cardinality**: exactly 1 primary input
